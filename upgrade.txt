  ---

  1. 📅 Critical UX Enhancement: Day-by-Day (Date-Scoped) Tracking
   * The Problem: Currently, the MacroGrid aggregates every single meal in AsyncStorage. As the user logs meals over several days, their calorie and protein
     counts will accumulate infinitely rather than resetting daily.
   * The Solution: 
       * Filter meals in src/app/(tabs)/index.tsx so only meals created today are calculated and displayed on the dashboard.
       * Add a Date Picker or Left/Right Date Navigators (< Yesterday, Today, Tomorrow >) on the home screen to let users look back at their history or
         pre-log meals.

  ---

  2. ⚡ Performance Optimizations
  As a user logs more meals, performance can degrade if not optimized.
   * Replace ScrollView with FlatList (List Virtualization):
      Currently, both meals.tsx and RecentMeals.tsx render meals using .map() inside a <ScrollView>. If a user logs hundreds of meals, React Native will
  render all of them at once, causing memory and UI lag.
       * Improvement: Use a <FlatList> in meals.tsx which virtualizes the list, rendering only the items visible on the screen and recycling DOM elements.
   * Component Memoization (React.memo & useMemo):
      The MealItem component doesn't need to re-render unless its specific meal data changes. Wrapping MealItem in React.memo and wrapping calculated values
  in useMemo will keep transitions silky smooth.
   * Fast, Structured Database (OP-SQLite / Expo SQLite):
      AsyncStorage is slow for large JSON payloads. Migrating to SQLite (via expo-sqlite) will allow fast querying (e.g., querying meals specifically between
  startOfDay and endOfDay) rather than pulling the entire log and filtering in memory.

  ---

  3. 🎨 Premium UI/UX & Interactive Features
  Users expect modern health apps to feel visual, smooth, and tactile.
   * Circular Progress Rings or Visual Progress Bars:
      Instead of just text (e.g. 1200 / 2000 kcal), display circular SVG progress rings or linear progress bars inside each MacroCard so users can instantly
  visualize how close they are to their targets.
   * Swipe-to-Delete Gestures:
      Instead of a static delete button, use react-native-gesture-handler and react-native-reanimated to implement a swipe-left-to-delete gesture for meals,
  which is the standard, satisfying mobile pattern.
   * Quick-Add Templates & Frequently Eaten Suggesters:
      Typing out "Protein Shake - 250 Calories - 30g Protein..." every single day is tedious. 
       * Improvement: Add a "Frequently Logged" section or autocomplete suggestion in add-meal.tsx so users can tap an item to pre-fill or instantly re-log
         common meals.
   * Weekly Trends Chart:
      Integrate a clean line/bar chart (using react-native-chart-kit or standard stylized CSS columns) showing the last 7 days of calorie and protein intake
  to encourage user consistency.
